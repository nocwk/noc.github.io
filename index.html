                                Multi-Site Routing (OSPF & EIGRP)
                            

                            

                                Designed and simulated a scalable corporate network connecting a headquarters to multiple remote branch offices using OSPF and EIGRP routing protocols for optimized path selection and sub-second convergence.
                            

                            

                                
Implementation Notes:

                                
Area 0 core distribution configured with reference-bandwidth 10000 and sub-second timers.

                                
Remote branch WAN links running EIGRP with Feasible Successor metrics computed for fast recovery.

                                
Two-way mutual redistribution configured with route-map tagging to prevent routing feedback loops.

                            

                        


                        

                            

                                HQ-R1-CORE.cfg
                                OSPF + EIGRP
                            

                            
router ospf 1
 router-id 1.1.1.1
 log-adjacency-changes
 network 10.0.0.0 0.0.0.255 area 0
 network 192.168.1.0 0.0.0.255 area 0
 auto-cost reference-bandwidth 10000
!
router eigrp 100
 network 172.16.0.0 0.0.255.255
 no auto-summary
 metric weights 0 1 0 1 0 0
 redistribute ospf 1 metric 10000 100 255 1 1500

                            
                        

                    

                


                

                    

                        

                            

                                Dual-Homed Enterprise Edge (eBGP)
                            

                            

                                Architected a dual-homed enterprise edge network utilizing external BGP (eBGP) for redundant ISP connectivity, manipulating route attributes to engineer precise inbound and outbound traffic flows.
                            

                            

                                
Implementation Notes:

                                
Primary transit through ISP-A configured with higher Local Preference (200) for outbound traffic.

                                
Secondary transit through ISP-B configured with AS-Path Prepending (3x) on outbound route-maps for inbound flow preference.

                                
Port Address Translation (PAT) deployed on edge routers for secure internal subnet internet connectivity.

                            

                        


                        

                            

                                EDGE-GW-BGP.cfg
                                DUAL eBGP
                            

                            
router bgp 65001
 bgp log-neighbor-changes
 neighbor 203.0.113.1 remote-as 64512
 neighbor 203.0.113.1 description PRIMARY-ISP-A
 neighbor 203.0.113.1 route-map SET-LP-IN in
 neighbor 203.0.113.5 remote-as 64513
 neighbor 203.0.113.5 description BACKUP-ISP-B
 neighbor 203.0.113.5 route-map PREPEND-OUT out
!
route-map SET-LP-IN permit 10
 set local-preference 200

                            
                        

                    

                


                

                    

                        

                            

                                Switching & Campus Layer 2 Hardening
                            

                            

                                Implemented inter-VLAN routing using a Router-on-a-Stick topology to securely segment HR, IT, and Finance departments, enforcing inter-departmental traffic policies via Extended Access Control Lists (ACLs). Configured Layer 2 redundancy and loop prevention using Rapid Spanning Tree Protocol (RSTP) and aggregated switch links using EtherChannel (LACP) to increase backbone bandwidth. Implemented Port Security on access switches to mitigate unauthorized network access.
                            

                            

                                
Implementation Notes:

                                
Access ports protected with Sticky MAC port security, limiting connections to 1 device with shutdown violations.

                                
Rapid Spanning Tree (RSTP) configured with BPDU Guard enabled on all access edge ports.

                                
Inter-departmental traffic regulated using Extended ACLs on router subinterfaces.

                            

                        


                        

                            

                                SW-ACCESS-01.cfg
                                L2 DEFENSE
                            

                            
interface FastEthernet0/1
 description HR-USER-PORT
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast
 spanning-tree bpduguard enable
 switchport port-security
 switchport port-security maximum 1
 switchport port-security mac-address sticky
 switchport port-security violation shutdown
