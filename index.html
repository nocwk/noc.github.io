SUB-01 Scalable Core Routing: OSPF Multi-Area & EIGRP Integration

Designed and simulated a scalable corporate network connecting a headquarters to multiple remote branch offices using OSPF and EIGRP routing protocols for optimized path selection and sub-second convergence.

Architecture Highlights:
  • OSPF Area 0 (Backbone) established across HQ Distribution Routers with tuned hello/dead timers (1s/4s) for high-speed link-fault detection.
  • Remote branch networks connected over serial/Gigabit circuits leveraging EIGRP with Feasible Successor paths pre-calculated for zero-downtime cutover.
  • Mutual route redistribution configured with administrative distance metric weighting and route-maps to prevent two-way routing feedback loops.

SUB-02 Dual-Homed Enterprise Edge: Redundant external BGP (eBGP)

Architected a dual-homed enterprise edge network utilizing external BGP (eBGP) for redundant ISP connectivity, manipulating route attributes to engineer precise inbound and outbound traffic flows.

Traffic Engineering Decisions:
  • Primary uplink engineered to ISP-A (AS64512) with higher Local Preference (200) for deterministic primary outbound internet transit.
  • Backup path routed to ISP-B (AS64513) with standard Local Preference (100) and AS-Path Prepending (3x) on egress to ensure asymmetric inbound path suppression.
  • Edge NAT/PAT overload pools mapped directly to route interfaces to maintain continuous session translation during ISP failover tests.
EDGE-GW-BGP.cfg [PEERING] MULTI-HOMED 
! --- Exterior BGP Peering ---
router bgp 65001
 bgp log-neighbor-changes
 neighbor 203.0.113.1 remote-as 64512
 neighbor 203.0.113.1 description PRIMARY-ISP-A
 neighbor 203.0.113.1 route-map SET-LP-IN in
 neighbor 203.0.113.5 remote-as 64513
 neighbor 203.0.113.5 description BACKUP-ISP-B
 neighbor 203.0.113.5 route-map PREPEND-OUT out
!
route-map SET-LP-IN permit 10
 set local-preference 200

SUB-03 Campus Switching: Inter-VLAN, RSTP Loop Mitigation & Port Hardening

Implemented inter-VLAN routing using a Router-on-a-Stick topology to securely segment HR, IT, and Finance departments, enforcing inter-departmental traffic policies via Extended Access Control Lists (ACLs). Configured Layer 2 redundancy and loop prevention using Rapid Spanning Tree Protocol (RSTP) and aggregated switch links using EtherChannel (LACP) to increase backbone bandwidth. Deployed Port Address Translation (PAT) on edge routers and implemented Port Security on access switches.

Security & Link Integrity Controls:
  • Port Security (Sticky MAC): Max 1 MAC per access interface, immediate shutdown violation state against unauthorized rogue laptop patching.
  • DHCP Snooping & DAI: Untrusted client ports inspected; ARP spoofing poisoning completely blocked across all user access ports.
  • Spanning Tree: BPDU Guard enabled on all PortFast access access points to prevent unauthorized bridge insertion.
SW-ACCESS-01.cfg [HARDENED] PORT SECURITY

interface FastEthernet0/1
 description HR-USER-PORT

 switchport access vlan 10
